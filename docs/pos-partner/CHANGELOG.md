# Changelog

## 1.0.0 - 2026-08-02

- Defined the verified Restec v1 bill, table, customer payment-session, and POS-originated payment routes.
- Added a Restec-branded, versioned payment webhook envelope and environment header.
- Defined request and webhook signing inputs, idempotency, retry, deduplication, and problem responses.
- Added environment-separated, scoped, expiring, rotatable, and revocable partner credentials.
- Added OpenAPI, Postman, curl, Node.js, C#, and Java integration assets.

This version does not add POS-initiated void, refund, reversal, or structured line-modifier endpoints.
