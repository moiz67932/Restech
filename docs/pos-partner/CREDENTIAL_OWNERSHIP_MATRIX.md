# Credential ownership matrix

| Value                           | Creator     | Stored by                                        | Issued/transmitted                                | Rotation                                                                                | Revocation                          | Environment-specific |
| ------------------------------- | ----------- | ------------------------------------------------ | ------------------------------------------------- | --------------------------------------------------------------------------------------- | ----------------------------------- | -------------------- |
| Partner/client ID               | Restec      | Both                                             | Onboarding secure channel                         | Stable                                                                                  | Partner offboarding                 | No                   |
| Restec location ID              | Restec      | Both                                             | Onboarding secure channel                         | Only on remapping                                                                       | Location disabled                   | Yes                  |
| API credential                  | Restec      | POS secret manager; Restec stores a one-way hash | Displayed once through an approved secure channel | Scheduled or incident rotation with approved grace                                      | Immediate server-side revocation    | Yes                  |
| Request-signing secret          | Restec      | Both secret managers; Restec stores encrypted    | Displayed once with API credential                | With API credential                                                                     | With API credential                 | Yes                  |
| Webhook-signing secret          | Restec      | Both secret managers; Restec stores encrypted    | Displayed once                                    | Requires a Restec-coordinated change window; dual-secret overlap is not available in v1 | Callback disabled or secret revoked | Yes                  |
| Callback URL                    | POS partner | Both                                             | Onboarding form                                   | Before endpoint change                                                                  | Callback disabled                   | Yes                  |
| External store/location ID      | POS partner | Both                                             | Onboarding form                                   | Controlled remapping                                                                    | Location disabled                   | Yes                  |
| Optional inbound POS credential | POS partner | Both secret managers; Restec stores encrypted    | Separate secure channel                           | Partner policy                                                                          | Partner revokes and Restec removes  | Yes                  |
| Optional mTLS details           | POS partner | Both                                             | Onboarding secure channel                         | Before certificate expiry                                                               | Certificate deny-list/removal       | Yes                  |
| Allowed IP requirements         | POS partner | Both                                             | Onboarding form                                   | Before egress change                                                                    | Remove allow-list entry             | Usually              |
| Technical escalation contacts   | POS partner | Both                                             | Onboarding form                                   | On personnel change                                                                     | Partner offboarding                 | No                   |

Restec never returns a stored secret after initial issuance. Sandbox values must never be promoted into production.
