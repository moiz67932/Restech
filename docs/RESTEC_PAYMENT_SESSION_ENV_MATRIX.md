# Restec Payment Session Environment Matrix

| Variable                                     | Code location                      | Secret                    | Sandbox                                                                   | Production initial value/type                         | Required                   | Absent effect                                                  | Redeploy        |
| -------------------------------------------- | ---------------------------------- | ------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------- | -------------------------- | -------------------------------------------------------------- | --------------- |
| `RESTEC_PAYMENT_SESSIONS_ENABLED`            | `apps/api/src/config.ts`, `app.ts` | No                        | `true` only after allowlist/contract readiness                            | `false`                                               | No; defaults false         | Routes return 404 and workers make no new session calls        | Yes             |
| `RESTEC_PAYMENT_SESSION_TTL_SECONDS`         | config, create route               | No                        | Integer, normally `900`                                                   | Integer; unused while disabled                        | No                         | Defaults 900                                                   | Yes             |
| `RESTEC_CHECKOUT_PUBLIC_BASE_URL`            | config, create route               | No                        | Exact HTTPS Restec API origin                                             | Exact production HTTPS origin before later enablement | Required only when enabled | Enabled config fails fast                                      | Yes             |
| `RESTEC_ALLOWED_PAYMENT_CHECKOUT_HOSTS`      | config, redirect validation        | No                        | Comma-separated exact hosts observed from approved real sandbox responses | Empty while disabled; never copy sandbox hosts        | Required only when enabled | Enabled config fails fast                                      | Yes             |
| `RESTEC_PAYMENT_SESSION_RETURN_POLL_SECONDS` | return route                       | No                        | Integer 1–30, normally `2`                                                | Same type; unused while disabled                      | No                         | Defaults 2                                                     | Yes             |
| `RESTEC_SECRET_ENCRYPTION_KEY`               | security and repositories          | Yes                       | Existing base64 32-byte key; unchanged                                    | Existing production key; unchanged                    | Yes                        | Startup fails                                                  | Yes             |
| `PAELY_PRIVATE_BASE_URL`                     | private client bootstrap           | Internal sensitive config | Existing sandbox private origin                                           | Existing production private origin                    | Yes                        | Startup fails                                                  | Yes             |
| `PAELY_SERVICE_ID`                           | private client                     | Internal identity         | Existing sandbox value                                                    | Environment-specific value                            | Yes                        | Startup fails                                                  | Yes             |
| `PAELY_PRIVATE_BEARER_TOKEN`                 | private client                     | Yes                       | Existing sandbox secret                                                   | Production-only secret                                | Yes                        | Startup fails                                                  | Yes             |
| `PAELY_PRIVATE_SIGNING_SECRET`               | private client                     | Yes                       | Existing sandbox secret                                                   | Production-only secret                                | Yes                        | Startup fails                                                  | Yes             |
| `PAELY_EVENT_SIGNING_SECRET`                 | event receiver                     | Yes                       | Existing sandbox secret                                                   | Production-only secret                                | Yes                        | Startup fails                                                  | Yes             |
| `PAELY_EVENT_SERVICE_ID`                     | payment-session event receiver     | Internal identity         | Approved sandbox sender identity                                          | Approved production sender identity                   | No; defaults `paely`       | Default identity is required; set explicitly for certification | Yes             |
| `RESTEC_INTERNAL_JOB_TOKEN`                  | dispatcher/evidence endpoints      | Yes                       | Existing sandbox secret                                                   | Production-only secret                                | Yes                        | Startup fails                                                  | Yes             |
| `RUN_REAL_PAYMENT_SESSION_CERTIFICATION`     | certification script only          | No                        | Explicit `true` per run                                                   | Never true                                            | No                         | Script refuses remote calls                                    | No API redeploy |

Do not determine enablement from `NODE_ENV`. The exact hosted-checkout hostname is intentionally not guessed in source control. Obtain it from a real approved private sandbox session, security-review it, then configure the exact host.
