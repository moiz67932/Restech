# Supabase Setup

Run `npm install`, `npm run db:start`, `npm run db:reset`, `npm run db:lint`, then `npm run db:types`. Docker Desktop and the repository-local CLI are required. Regenerate types after schema changes. Browser code never receives the service-role key. API keys use prefix plus scrypt hash; retrievable signing, connector and webhook secrets use AES-256-GCM encryption.
