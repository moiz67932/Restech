# Partner Onboarding

Create the partner, user roles, restaurant, location, and connection in the correct environment. Verify connector documentation and version, map public tables through controlled onboarding, configure an HTTPS webhook, show newly generated API and webhook secrets once, and store only hashed or encrypted forms. Complete sandbox authentication, bill, payment, duplicate, timeout, failure, refund, and replay exercises before requesting production review. Production uses new credentials and a separately approved connection.
